# PartForge 1.0.0 Beta 1

First public beta of PartForge.
The Python package version is `1.0.0b1`; the corresponding GitHub release tag is `v1.0.0-beta.1`.

PartForge creates and maintains database component libraries (DbLib) for Altium Designer on Windows 10/11.
It was developed largely through vibe coding with AI assistance and is in an early beta stage.
Expect bugs and changes. Check generated parts, symbols and footprints against manufacturer documentation
before use, and keep backups of your libraries.

## Included in this beta

- Local library management with SQLite, parts tables, history, backups and DbLib generation.
- Manufacturer series generation, CSV/Excel/ODS import, CSV/Excel export, symbol and IPC footprint generation.
- Optional Claude-powered PDF datasheet analysis with review, cost estimates and a per-import spending limit.
- Import of existing Altium libraries, house-style extraction, batch editing and STEP-model previews.
- Altium installation, component checks and monitoring of symbols and footprints edited in Altium.
- English and German interfaces with dark and light themes.

## Installation

Download `PartForge-v1.0.0-beta.1-windows-x64.zip` from the
[release assets](https://github.com/trosenbusch/PartForge/releases/tag/v1.0.0-beta.1), extract the complete folder,
and run `PartForge.exe`. Keep the accompanying files with the executable.
`PartForge-v1.0.0-beta.1-source.zip` contains the source snapshot; `SHA256SUMS.txt` lists both archive checksums.
To check a downloaded archive in PowerShell, run `Get-FileHash .\PartForge-v1.0.0-beta.1-windows-x64.zip -Algorithm SHA256`
and compare the result with `SHA256SUMS.txt` before extracting it.

Follow the [README](https://github.com/trosenbusch/PartForge/blob/v1.0.0-beta.1/README.md#installation-and-startup) for prerequisites and installation instructions.
The altium-designer-mcp library writer is installed separately and is not included in PartForge.
Altium Designer and its licenses are also separate. Claude analysis requires your own API key and can incur charges.

## Known limitations

- Altium integration has been tested with Altium Designer 26.10. Other versions and desktop configurations need validation.
- Generated data and AI analysis can be incomplete or incorrect. Review pin assignments, dimensions, land patterns,
  part numbers and symbols before use in a design or ordering parts.
- The Murata GRM series catalog has not been verified against manufacturer data.
- Altium's Components panel and “Update Parameters From Database” dialog are not tested automatically.
- Large XLSX exports and writes to large PcbLib files can take several seconds. CSV export is faster.
- Database backups are not compressed and can use substantial disk space.
- Packaged Windows executables are unsigned, which can trigger a SmartScreen warning.
- PostgreSQL multi-user operation requires a source installation.
- The detailed user manual is currently in German; interface translations may still have gaps.
- Datasheets submitted for AI import are sent to the Claude API; other library data stays local.

The [changelog](https://github.com/trosenbusch/PartForge/blob/v1.0.0-beta.1/CHANGELOG.md) lists the features and current limitations in more detail.
Report reproducible problems using the repository's bug-report form. Follow
[the security policy](https://github.com/trosenbusch/PartForge/blob/v1.0.0-beta.1/SECURITY.md) for private disclosure of security issues.
